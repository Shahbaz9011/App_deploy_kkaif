# K-KAIF Enterprises – Machinery Services App

A professional responsive website for K-KAIF Enterprises covering:
- 10 Ton / 15 Ton Farana
- Hydra Crane
- JCB
- Truck / Transport
- Loading / Unloading
- Material Shifting
- Driver / Operator support
- Machinery and project site support

## Run locally
1. Install Node.js 18+.
2. Open terminal in this folder.
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:3000`

## Enquiry form
Submissions are received by `POST /api/requests` and stored in `data/requests.json`.
For a production deployment, connect this endpoint to your preferred email/CRM/database.
